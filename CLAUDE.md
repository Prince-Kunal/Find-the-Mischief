# Find the Mischief

Offline, single-game Android party app played by passing one phone around. Everyone sees the same secret word (**the Truth**) except **the Trickster(s)**, who may get a hint (**a Whisper**). Players give one-word clues (**the Telling**), then vote to **banish** a suspect (**the Judgement**).

The full spec and phase list is in `findTheMischief_PLAN.md`. Read it before starting a phase.

## Working rules
- **One phase at a time.** At the end of a phase: `./gradlew assembleDebug`, `./gradlew test`, summarize changes, list what to test by hand on the phone, suggest a commit message, then **stop and wait**. Commit only when asked.
- The user is new to Android: explain any new Android concept in 2–3 plain sentences.
- If something in the plan is unclear or seems wrong, ask instead of guessing.
- Don't build a game hub, registry or "coming soon" screens. This app has exactly one game; keep game logic in `game/` so it could be reused later.

## IP rule (always)
Public-domain Norse mythology only. **Nothing from Marvel**: no MCU likeness, no Marvel-style horned helmet, no TVA or show references, no movie quotes, no "Marvel"/"MCU" text, no logos. All art is original (Compose drawing / vectors we make). Sounds are generated by our own scripts, never downloaded.

## Stack (fixed, don't swap)
Kotlin · Jetpack Compose + Material 3 · single Activity · MVVM (ViewModel + `StateFlow`, unidirectional data flow) · Navigation Compose with type-safe `@Serializable` routes · kotlinx.serialization for `assets/words.json` · DataStore Preferences for settings and player names · `SoundPool` for sounds in `res/raw/` · haptics via `HapticFeedback`/`Vibrator` · JUnit for pure-Kotlin game logic.
- **No Hilt or other DI** — manual constructor injection via `AppContainer` (owned by `MischiefApp`).
- **No Room.** No internet permission, no backend, no ads, no analytics.
- minSdk 26, targetSdk latest stable. AGP 9 (built-in Kotlin support, no `kotlin-android` plugin). Versions live in `gradle/libs.versions.toml`.

## Package layout (`com.prince.findthemischief`)
- `MainActivity`, `MischiefApp` (Application), `AppContainer`, `MischiefNavHost` (routes + NavHost)
- `core/` — `audio/SoundPlayer`, `haptics/Haptics`, `data/SettingsRepository`
- `ui/theme/` — `Color`, `Type`, `Shape`, `Theme`
- `ui/components/` — `GoldFrameCard`, `RuneDivider`, `MischiefButton`, `SerpentEmblem`, `MischiefBackground`
- `game/` — `data/` (WordRepository, WordModels), `domain/` (MischiefEngine, GameState: **pure Kotlin, no Android imports**), `GameViewModel`
- `screens/<name>/` — one package per screen (home, setup, reveal, telling, judgement, result, settings)

## Conventions
- Composables only render state and send events; no game logic in UI.
- Files under ~300 lines.
- User-facing text goes in `res/values/strings.xml`, using the in-app vocabulary: Trickster, the Honest, the Truth, a Whisper, the Telling, the Judgement, Banish, "Mischief found!", "The Trickster prevails."
- `MischiefEngine` takes its `Random` as a parameter so tests are deterministic.
- Every screen sits inside `MischiefBackground` and handles insets (`safeDrawingPadding()`).
- Pass-the-phone safety (Phase 5): never show a card without going through that player's Pass screen; no animation may bring a card into view; `FLAG_SECURE` and back-blocking on reveal screens.

## Theme
- Dark-only Material 3, no dynamic colour. Use the named colours in `ui/theme/Color.kt`, never raw hex in screens:
  NearBlack `#0B0F0D` (background) · DeepEmerald `#0F3D2E` (surface) · MischiefGreen `#2E8B57` (primary) · OldGold `#C9A227` (accent) · Parchment `#E8DFC8` (text) · BloodRed `#8B1E1E` (error).
- Fonts are bundled in `res/font/` (OFL; licences in `licenses/fonts/`): **Cinzel** for titles/big words (display/headline/title styles), **Inter** for body/labels, **Noto Sans Runic** for decorative runes (`RuneTextStyle`). Cinzel and Inter are variable fonts.
- Decorative elements (runes, emblems) are hidden from screen readers. Legibility first: high contrast, big words, touch targets ≥ 48dp (`MischiefButton` is 56dp).

## Commands
- Build: `./gradlew assembleDebug`
- Unit tests: `./gradlew test`
- Install on phone: `./gradlew installDebug` (phone is on **Wi-Fi wireless debugging**). If `adb devices` lists nothing, ask the user to re-pair from Android Studio — don't try to fix it.
